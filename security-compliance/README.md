# 🛡️ Security & Compliance

This folder documents my hands-on exploration and understanding of Microsoft 365 Security & Compliance (Microsoft Purview). My goal is not to master every advanced E5 feature, but to clearly understand the entire ecosystem and practice everything available in my tenant while simulating the rest.

---

## 📘 Overview

Microsoft Purview handles data protection, governance, compliance, and risk across Microsoft 365.  
In this section, I worked through:

- 🏷️ Sensitivity labels (files and emails)
- 🗄️ Retention policies
- 🔍 Basic audit logging
- 🔎 eDiscovery Standard
- 🚫 SharePoint and OneDrive external sharing controls (DLP simulation)
- 📊 Compliance Manager (read-only)
- 🕵️ Data Security Investigations (UI exploration)
- 🧠 Conceptual understanding of advanced Purview features

This gives me full visibility into how organizations secure data and enforce compliance inside Microsoft 365.

---

## 🏷️ Sensitivity Labels (Files and Emails)

**Hands-on:**
- Created custom labels  
- Added headers and footers  
- Published labels to myself  
- Applied labels in Office apps  
- Tested external sharing behavior  

**Understanding:**  
Labels classify and protect content using encryption, access restrictions, and visual markings.

---

## 🗄️ Retention Policies

**Hands-on:**
- Created retention policies for Exchange, SharePoint, and OneDrive  
- Configured retain-only and retain-then-delete policies  
- Verified policy application  

**Understanding:**  
Retention ensures data is kept or deleted based on legal or organizational requirements.
