# ⚙️ Automation

This folder covers my hands-on exploration and understanding of automation across Microsoft 365. My goal is to clearly understand how PowerShell, Graph API, and admin workflows automate identity, mail, devices, and compliance tasks, and to practice every core automation concept available in my tenant.

---

## 📘 Overview

Automation is how Microsoft 365 admins scale management, reduce manual work, and enforce consistency across the environment.  
In this section, I worked through:

- 🖥️ PowerShell modules (Entra ID, Exchange Online, Intune)
- 🔗 Microsoft Graph API concepts
- 🔄 Bulk user and group operations
- 📬 Automated mailbox and group management
- 📱 Device management automation
- 🛡️ Policy deployment automation
- 🧠 Conceptual understanding of advanced automation workflows

This gives me a complete picture of how automation ties together identity, mail, devices, and compliance.

---

## 🖥️ PowerShell Automation

**Hands-on:**
- Connected to Entra ID, Exchange Online, and Intune PowerShell modules  
- Listed users, groups, devices, and mailboxes  
- Performed bulk operations (create, update, remove)  
- Automated common admin tasks  

**Understanding:**  
PowerShell is the primary automation tool for Microsoft 365, enabling repeatable and scalable workflows.
