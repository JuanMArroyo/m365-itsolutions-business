# 📱 Microsoft Intune

This folder covers my hands-on exploration and understanding of Microsoft Intune within Microsoft 365. My goal is to clearly understand how device management, compliance, app deployment, and endpoint security operate across the tenant, and practice every core feature available without needing advanced licensing.

---

## 📘 Overview

Microsoft Intune is the cloud-based endpoint management platform for devices, apps, and security policies.  
In this section, I worked through:

- 📱 Device enrollment and management
- 🔐 Compliance policies
- 📦 App deployment
- 🛡️ Configuration profiles
- 🔄 Conditional Access integration
- 🧪 Testing device compliance behavior
- 🧠 Conceptual understanding of advanced Intune and Endpoint Security features

This gives me a complete picture of how organizations manage and secure endpoints across Microsoft 365.

---

## 📱 Device Enrollment

**Hands-on:**
- Enrolled Windows devices into Intune  
- Verified device status and inventory  
- Tested device sync and policy refresh  

**Understanding:**  
Enrollment brings devices under management so Intune can enforce security, compliance, and configuration.

---

## 🔐 Compliance Policies

**Hands-on:**
- Created compliance policies  
- Configured password requirements, encryption, and OS version rules  
- Tested compliant vs non-compliant device behavior  

**Understanding:**  
Compliance policies define the minimum security posture required for devices accessing organizational resources.

---

## 📦 App Deployment

**Hands-on:**
- Added and deployed apps to managed devices  
- Tested installation behavior  
- Verified app status and reporting  

**Understanding:**  
Intune delivers applications to devices, ensuring users have the tools they need while maintaining security.

---

## 🛡️ Configuration Profiles

**Hands-on:**
- Created configuration profiles for Windows  
- Applied settings such as security baselines and device restrictions  
- Tested policy enforcement  

**Understanding:**  
Configuration profiles push settings and restrictions to devices, controlling behavior and security.

---

## 🔄 Conditional Access Integration

**Hands-on:**
- Connected compliance policies with Conditional Access  
- Tested access blocking for non-compliant devices  

**Understanding:**  
Conditional Access uses device compliance to enforce Zero Trust principles across Microsoft 365.

## 🧪 Testing and Troubleshooting

Troubleshooting is a core skill for endpoint management and ensures policies behave as expected.
